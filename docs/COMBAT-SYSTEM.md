> 分类合并飘字与 T154 回归已接入。

## 0. 规格核对

- 新设想明确：**元素 6 种**（物理/雷霆/水/冰/火/腐蚀），**形态 4 种**
  （动能/能量/爆炸/切割）；`能量` 是形态而不是元素。
- 任务描述里仍保留旧说法“7 属性”；本实现以新设想和主人此前的修正为准，
  不保留第 7 个 `DamageType`。
- 旧 v2.6 的“线性衰减 + 10% 保底 + 按最大生命过穿”全部废弃，换成新公式。
  这是破坏性重构，旧存档不需要迁移内容，但战斗数值会明显变化。

## 1. 元素 × 形态

| 维度 | 取值 | 作用 |
|---|---|---|
| 元素 | 物理 / 雷霆 / 水 / 冰 / 火 / 腐蚀 | Combo、Aura、元素抗性、腐蚀减甲 |
| 形态 | 动能 / 能量 / 爆炸 / 切割 | 力场盾、跳弹、过穿、能量抗性 |

典型区分：

- **雷霆-动能** = 磁轨炮：真实弹丸，吃跳弹，可过穿，重甲靠白值/穿透率。
- **雷霆-能量** = 电弧塔/天罚：无质量，无视力场盾，不吃跳弹，不过穿。

## 2. 穿透与减伤公式

每发武器有 `P_rate`（基础穿透率）、`P_flat`（穿透白值）、`C_decay`
（平方衰减常数）、`C_ricochet`（跳弹增长系数）。

```text
若 A <= P_flat:
    P_actual = P_rate
否则:
    P_actual = max(0, P_rate - C_decay * ((A - P_flat) / P_flat)^2)

A_eff = A * (1 - P_actual)
R_armor = A_eff / (A_eff + K)          // K = 100
D_armor = D_base * (1 - R_armor)
D_resist = D_armor * (1 - R_E) * (1 - R_Energy)   // 能量抗性仅能量形态
D_final = D_resist * M_combo
```

- **没有旧的 10% 刮痧保底**；未跳弹时只保留“至少 1 点或基础伤害 5%”的
  防浮点/防负伤害下限。
- `P_flat` 为 0 时，任何正护甲都会把穿透率压到 0；这类武器只适合特殊内容。
- 代码：`ArmorPen.java`、`Dmg.java`。

## 3. 前置拦截管线

### 3.1 力场盾

- 非能量形态：伤害先扣 `Shieldc.shield()`，盾破后的溢出部分才进入后续管线。
- 能量形态：直接跳过力场盾，打本体；护盾值不消耗。
- 盾完全吸收时：本体不掉血、不挂 Aura、不触发 Combo。
- 代码在 `Dmg.hit()` 的 shield 分支，实际扣本体时临时把盾置 0，避免
  `damagePierce` 再次吸盾。

### 3.2 跳弹

```text
条件：A > P_flat
P_ricochet = min(0.90, (A - P_flat) * C_ricochet)
结果：命中 RNG 时 D_final = 0，立刻结束；不挂 Aura、不溅射。
```

- 能量形态不吃跳弹（`DamageForm.ENERGY` 直接跳过）。
- `C_ricochet` 没有统一建议值，当前按弹种给 0.01~0.04 的低系数；
  测试环境可用 `Dmg.ricochetRoll` 强制 roll。
- 代码：`ArmorPen.ricochetChance()`、`Dmg.hit()`。

### 3.3 过穿

```text
条件：形态 = 动能，且 P_flat >= 当前护甲 A × 2
结果：D_final = D_base * 0.30
      跳过抗性、Combo、Aura、腐蚀附着与 AOE 溅射。
```

- 只有动能形态；能量/爆炸/切割不触发。
- 当前按公式严格实现：**A=0 时任何正白值的动能武器都会过穿**（30% 伤害）。
  这是新设想的直接结果，也是 AP 炮弹打无甲小兵会掉伤害的原因；需要实机确认。
- `Bullet.data` 打标记，`Dmg.splash()` 看到标记直接返回，连原版状态/点燃都跳过。

## 4. 防御端乘区

1. **元素抗性 `R_E`**：按单位/方块名注册，默认 0，上限 0.90。
2. **能量抗性 `R_Energy`**：只在能量形态参与乘区，默认 0，上限 0.90。
3. **Combo**：在抗性之后乘算；触发后消耗旧 Aura 及其原版可见状态，再挂新 Aura。

新设想没有给具体单位的抗性数值，所以当前 `Resistance` 表默认为空，只提供
`Resistance.set(...)` / `setEnergy(...)` 接口。图鉴会显示登记过的抗性；未登记显示“无”。

## 5. 元素与 Combo

| 本元素 | 旧附着 | 倍率 | 名称 |
|---|---|---:|---|
| 雷霆 | 水 | 1.50 | 感电 |
| 火 | 冰 | 1.50 | 融化 |
| 水 | 火 | 1.50 | 蒸发 |
| 雷霆 | 冰 | 1.35 | 超导 |
| 冰 | 水 | 1.25 | 冻结 |
| 物理 | 冰 | 1.25 | 碎冰 |

- **腐蚀不参与 Combo**；腐蚀只做附着/减甲。
- 物理可触发碎冰但不写入 Aura。
- 为避免原版 affinity 绕过 Combo（例如潮湿+电击额外 14 伤害），
  `ElementCombo` 在换元素时先移除旧原版状态，再挂新状态；腐蚀是例外，
  保留潮湿以支持酸蚀。
- Aura 持续 4 秒（240 tick）；重复命中刷新。

## 6. 腐蚀

- 不参与 Combo；命中腐蚀元素后登记腐蚀激活。
- 每 tick 永久扣除目标基础护甲的 **0.01%**（`0.0001 × A_max`）。
- 普通上限 **15%** 基础护甲；潮湿/酸蚀时速率减半、上限 **8%**。
- 削减量在目标死亡前不恢复；腐蚀 Aura 过期后不再继续扣，但已扣部分保留。
- 代码：`Corrosion.java`；事件由 `Dmg.load()` 注册到 `Trigger.update`。

当前没有给腐蚀“每 tick 真实伤害”的具体数值，所以只实现永久减甲；
如果主人要腐蚀本身造成独立真伤，需要再补一条数值曲线。

## 8. 待主人确认 / 当前暂定

1. **“防浮点保底”**：原文写“至少 1 或基础伤害的 5%”，当前取
   `max(1, D_base × 5%)`；如果只要 `1`，改 `Dmg.hit()` 一行。
2. **抗性数值**：新设想没有给单位抗性表，当前全部 0，只留接口和测试；
   需要主人给具体单位/元素数值才能形成实际克制。
3. **腐蚀持续时间**：当前按 4 秒 Aura 生效，重复命中刷新；已扣护甲永久保留。
   如果腐蚀应持续更久/永久扣到上限，需要改 `Corrosion.activeTicks`。
4. **腐蚀真伤**：当前只减甲，没有每 tick 真伤；新设想没有给伤害数值。
5. **跳弹系数**：没有建议值，当前按弹种 0.01~0.04；可实机调。
6. **过穿 A=0**：严格公式会让所有正白值动能武器打无甲目标都过穿并掉到 30%；
   若想要“白值明显高于护甲才过穿”，需要加最小护甲/最小白值限制。
7. **AP 炮弹**：动能+溅射，过穿时跳过溅射；与旧版相比是显著 nerf，需要实机确认。
8. **切割形态**：枚举已建，但当前没有切割武器内容。
9. **原版电弧塔连锁**：逐跳仍是原版 `LightningBulletType` 结算，没有逐跳走新管线。
10. **实机 UI**：无头回归不渲染 UI，详情页/图鉴/设置页的视觉需要实机验收。
