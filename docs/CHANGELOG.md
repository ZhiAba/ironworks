## 0.63.x

### 0.63.3 — 冷却液回路与详情页修复

- **修复**：热冷却液现在从 **4×6 整块的外圈**排出，挂在链接块那一侧的管道/储罐也能接到（之前只遍历主块 4×4 的邻近格）。
- **修复**：链接块转发液体时按主块剩余容量截断，冷却液不会再突破 2000 上限（实测 95,936 → 2000 封顶）；主块自身的 acceptLiquid 也加了容量判断。
- **修复**：详情页冷却液条重复——原版会为消耗液体自动加一条 liquid-<name>，现在移除，只保留带数值的自定义条，并显示「当前/上限」。
- **修改**：2×3 高级模块详情页尺寸改为按包围盒显示 2×3（之前显示 2×2），并补充「模块加成 / 模块功率」两项。
- **测试**：新增 T102（链接块一侧进液 + 容量封顶 + 热液从链接侧排进储罐）；T1–T102 全量回归全绿（21 条断言）。

### 0.63.2 — 链接块伪装成主块 + 放置幽灵修复

- **修改**：链接块把名称、图标、血条、消耗显示全部委托给主块（`getDisplayName/getDisplayIcon/displayBars/displayConsumption`），并直接共享主块的物品/液体池——点选底部或高级工具查看时显示的是「全域算力集群」本体，不再暴露 `compute-cluster-link`。
- **修改**：链接块 `isHidden()` 恒为 true、`inEditor = false`，不再出现在方块列表里。
- **修复**：放置幽灵不再由 `drawPlace` 二次绘制不透明贴图——改由 `drawPlan → drawPlanRegion` 统一绘制，恢复原版的半透明 + 呼吸闪白，地块选择标线不再被盖住。
- **测试**：T95–T101 子集全绿（断言 11/11）。

### 0.63.1 — 修复整图贴图偏移半个格子

- **修复**：主集群 / 高级模块的整图绘制中心算错半个格子——Mindustry 的 tile 中心在 `x*8` 而不是 `x*8+4`，之前用 `(x1+x2+1)/2*8` 导致整张贴图向右上偏 4 世界单位（实机截图确认）。
- **修改**：贴合光带的格子边界同步改为 `x*8 ± 4`。
- **测试**：T95–T101 子集全绿（断言 11/11）。


### 0.63.0 — 一体贴图、冷却转化与数值上限

- **修改**：4×6 主集群与 2×3 高级模块改为**整张一体贴图**（对齐新视界的做法：主块画整图、链接块 `draw()` 留空），不再有拼接缝；另出方形 UI 图标 `*-ui` 供建造菜单使用，放置幽灵与蓝图预览也按整块包围盒居中。
- **新增**：链接块代理——点链接块显示主块的选中框，伤害打到链接块会转给主块。
- **修改**：超速数值定为 **基础 50%，全局上限 250%**（模块加成计入上限，不再叠加到 450%）。
- **新增**：冷却回路——每秒消耗 240 石墨烯冷却液并转化为等量热冷却液；热冷却液存满 2000 后效率归零（不再空烧），并可从机器四周排出。
- **修改**：液体存量 480 → **2000**；新增石墨烯冷却液 / 热冷却液两条独立液体条。
- **测试**：T95 期望改为 boost=70；新增 T101（容量 2000、基础超速 50%、转化速率≈240/秒）。

## 0.62.x

### 0.62.0 — 矩形占地：4×6 主集群 / 2×3 高级模块

- **新增**：链接块机制（参考新视线模组 NewHorizon 的 `BasicMultiBlock` / `LinkBlock`）：主方块 + 隐藏链接块拼出矩形占地。
  - 主集群 = 4×4 核心 + 底排两个 2×2 链接块 → 占地 **4×6**；
  - 高级模块 = 2×2 核心 + 底排两个 1×1 通风块 → 占地 **2×3**。
- **修改**：贴合判定改为「包围盒 + 整边覆盖」，挂在链接块那一侧的模块也能被主集群识别；详情页尺寸显示 4×6。
- **修复**：方向判定上下颠倒的旧 bug —— 模块在上应 dir=2、在下应 dir=0；四方向由 T97b 断言覆盖（R=3 L=1 D=0 U=2）。
- **新增**：链接块把相邻液体转发给核心（冷却液可以从链接块一侧接入）；隐藏、不可建造、不可拆除。
- **新增**：主块被拆/被毁时链接块一起清除；读档按**相对坐标**重新绑定（蓝图整体平移后仍能恢复）；主块消失后遗留的链接块 10 tick 内自毁。
- **视觉**：矩形模块无法用旋转贴图表达朝向，改为在贴合边绘制呼吸光带；方形模块继续使用 `-2` 变体旋转。
- **美术**：重画 `compute-cluster` 128×128、`compute-cluster-link` 64×64、`compute-advanced` 64×64、`compute-advanced-link` 32×32。
- **测试**：T95–T97 按新占地重写，新增 T98（链接块生成与绑定）、T99（拆除连带清理）、T100（读档相对坐标重绑）；T1–T100 全量回归通过。
- **存档兼容**：主集群从 6×6 变为 4×6，旧存档里的 6×6 集群需要拆掉重建。

### 0.60.0 — 全域算力集群（区块超速）

- **新增**：主方块「全域算力集群」——设计 4×6，因引擎只支持正方形方块，实现为 **6×6**；
  基础超速 50%~250%（随供电与冷却效率线性），四邻挂载模块的加成额外叠加，**上限 +200%**。
- **机制**：每 4 刻对全图建筑 applyBoost；基础耗电 32460/秒，每个挂载模块把自己的功率计入总耗电；
  需要石墨烯冷却液 60/秒；没电或缺冷却液时整机不工作、加成不生效。
- **新增**：4 种外挂模块（被动墙，必须贴着主集群四周）：
  - 微型 1×1：+1.35%，930/秒
  - 基础 3×3：+7%，1950/秒
  - 高级 3×3：+14%，6825/秒（设计 2×3，引擎限制改 3×3）
  - 量子 2×2：+20%，12420/秒
- **实现记录**：普通 Block 子类不会自动生成建筑，模块改用 Wall 基类后才可放置。
- **测试**：T95（挂载量子模块 → 超速 270%、效率 1）、T96（12 个模块加成封顶 200%）。

## 0.56.x

### 0.56.3 — 炮口单位修复
- **修复**：闪电从炮塔前方远处发出、光束显得过宽。

### 0.56.0 — 天罚：四炮口电弧塔

## 附：验证与部署约定

- 每个版本必须通过 `bash tools/chain-test.sh`（当前 T1–T93）再部署。
- 构建：`bash build.sh` → `out/ironworks.jar`（Android 需要 `.class` + `classes.dex`）。
- 部署：Shizuku `phone_sh` 复制到两个客户端；**必须完全重启游戏**才加载新 jar。
- 回归一次只能开一个实例；改动测试脚本时不要同时跑回归（bash 增量读取会读坏）。
