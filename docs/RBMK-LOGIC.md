# RBMK 逻辑控制码（3.6.0.0）

> 原版逻辑块通过 `control` 指令的 `config` 访问写 RBMK；通过 `sense` 读取只读状态。
> 逻辑编辑器里选择 **配置 / config**，值填下表中的数字。面板与逻辑共用同一个 `applyConfig(int)`，
> 不引入第二套控制逻辑。

## 一、可写控制码

### 通用（单堆与 12×12 分区堆）

| 值 | 动作 |
|---:|---|
| `-1` | SCRAM：插入全部控制棒 |
| `-2` | 武装注硼管线（之后才接收硼酸） |
| `-3` | 手动模式下切换本堆通知静音 |
| `-4` | 解除 SCRAM 锁存并复位跳闸 |
| `-5` | 切换堆芯注水开关 |
| `-6` | 复位卡棒 |
| `-10` | 半自动模式 |
| `-11` | 全自动模式 |
| `-12` | 强制手动模式 |
| `0..99` | 半自动/全自动：目标功率百分比；手动：控制棒插入百分比 |
| `1000..1099` | 最高水位线：`(v-1000)%` |
| `2000..2099` | 最低水位线：`(v-2000)%` |
| `3000..3099` | 手动模式单区冷却节流：`(v-3000)%`；未选分区时写全部 9 区 |
| `4000..4099` | 堆芯注水速率：`(v-4000)%` |

### 12×12 分区堆额外

| 值 | 动作 |
|---:|---|
| `-20` | 选择 1 区 |
| `-21` … `-28` | 选择 2 … 9 区 |
| `-30` | 取消分区选择（总控） |
| `0..99` | 有选中分区时写该区目标功率/棒位；未选中时写全部 9 区 |

## 二、只读状态（sense）

| `LAccess` | 含义 |
|---|---|
| `heat` | 归一化堆温/热功率（0–1 量级） |
| `progress` / `efficiency` | 当前通量（归一化） |
| `totalLiquids` | 当前液体总量 |
| `liquidCapacity` | 液体总容量 |
| `health` / `maxHealth` / `armor` | 结构生命与护甲 |

温度、压力、水位、分区温度等**物理量不可写**；逻辑只能通过 `sense` 读，或走上面的控制码间接操作。
`config` 传非数字/非可解析字符串时回退到原版 `Building.control`，不会误改堆芯。

## 三、示例

```text
# 全自动，目标 80% 功率
control config 80

# 切手动，选中 3 区，目标 45%
control config -12
control config -22
control config 45

# SCRAM
control config -1

# 读堆温
sensor result reactor heat
```

## 四、边界

- 控制码在服务端执行；多人游戏中由服务端权威结算。
- 逻辑写入的是**操作意图**，不绕过物理：无燃料、无水、跳闸锁存、卡棒仍按原有物理/安全逻辑生效。
- 不新增可写温度/压力字段；需要扩展时先在本文档登记，再改 `applyConfig`。
