# 铁流工业 Ironworks

Mindustry 模组。产线按真实冶金顺序组织：**先提炼、再精炼、最后成形**，
再往下接弹药链与战术支援。

## 产线主干

```
铁砂(沙) --磁选--> 铁精矿
水 --电解--> H2 + O2
                │     │
         氢还原炉    转炉
                │     │
             铁锭 --> 钢锭 --轧机--> 钢板 --> 钢板墙
```

另有一条碳冶金支线（高炉，用煤还原），以及从钢板分出来的
板材线、精炼线、脱硫/火药线、弹药线、桶装物流线。

→ 钢锭/钢板。**弹药是独立大类，不作为任何合成原料。**

## 关键机制

- **MultiCrafter（自研）**：一座方块多配方，可在界面切换；详情页列出全部配方与动态电耗。
- **同操作合并**：压延、电解、冲压、总装各只保留一台机器，用配方切产物。
- **熔融金属链**：高炉出铁水，转炉顶吹氧气出钢水，连铸成锭。炼钢靠焦炭与熔体显热，不烧电。
- **科技树两条独立线**：材料线与建筑线都直接挂在基础核心下，
  解锁时期由研究成本（铜/铅/硅/钛/钢板…）决定，不被原版节点顺序拖着走。
- **电的位置**：电只出现在电弧炉（把海绵铁重熔炼钢）——那是工业时代的事。
- **状态光环**：支援方块给范围内友军刷状态，耗电按秒结算。
- **破甲**：腐蚀的持续伤害走 `intervalDamagePierce`，无视护甲。
- **玉碎**：挂上状态的单位阵亡时爆裂，只伤敌方。
- **外挂装甲**：独立于单位的装备，装上后叠加真实护甲值并附带专属状态；
  一件一块、装上不脱落、一个单位只能穿一件。

## 平衡

`tools/balance.js` 用「铜当量」递归算成本，输出弹耗/秒、成本/秒、DPS 与效率：

| 炮塔 | 弹药 | 成本/秒 | DPS | 效率 |
|---|---|---|---|---|
| 速射炮 | 铜制弹药 | 5.5 | 120 | 22 |
| 穿甲炮 | 铅芯被甲 | 2.5 | 72 | 29 |
| 穿甲炮 | 腐蚀弹 | 2.9 | 96 | 33 |
| 穿甲炮 | 钛芯穿甲 | 2.4 | 101 | 43 |
| 穿甲炮 | 凝固汽油弹 | 1.8 | 91 | 51 |
| 穿甲炮 | 钛超压 | 3.4 | 216 | 64 |

效率低不等于弱：腐蚀弹买的是无视护甲与减速，凝固汽油弹买的是点燃地面。

## 构建与安装

```bash
bash build.sh     # -> out/ironworks.jar
```

依赖：JDK 17+、`Mindustry-160.1.jar`、`r8-9.5.26.jar`（路径见 build.sh 顶部）。

安装：把 jar 放进 `/sdcard/Android/data/<包名>/files/mods/`
（容器里读不到 `Android/data`，用 `phone_sh cp` 复制）。

## 已知限制

- 没有自己的单位线；光环与装甲目前服务的都是原版单位
- 新增方块会改变方块 ID 顺序，旧蓝图 `.msch` 可能失效
- 长局实机平衡（多炮塔混编、大规模光环）尚未验证
